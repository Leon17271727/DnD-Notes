In [[Elysium]] gilt grundsätzlich der gebräuchliche Kalender. *(Genaue Infos zum Kalender folgen.)*

Die vier Jahreszeiten tragen jeweils einen besonderen Namen:

| Jahreszeit | Name | Englisch |
| ---------- | ---- | -------- |
| Frühling   | [[Jahreszeit der Dryade]]  | Dryad Season |
| Sommer     | [[Jahreszeit der Drachen]] | Dragon Season |
| Herbst     | [[Jahreszeit der Weihe]]   | Hallow Season |
| Winter     | [[Jahreszeit der Geister]] | Spirit Season |

In den älteren [[Jahr 3164AD|Chroniknotizen]] werden die englischen Namen verwendet.
